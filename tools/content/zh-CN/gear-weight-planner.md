## 这个工具算什么，什么时候不能用

长距离越野和夏季路跑里，背包里每多一百克，几十公里累积下来都是负担；但盲目减重最容易先砍掉安全装备。这个工具把强制清单和自选装备逐项登记重量，再加上背包自重、饮水和能量食物，汇总基础重量、背负总重和强制、自选两类重量，按体重归一化算出负重占比，指出最重的单件装备，并在负重偏高或饮水携带过大时给出取舍提示。它的目的是让减重决策有据可依，而不是替你决定穿什么、买什么。

它适合赛前整理越野包、核对强制装备、比较两套打包方案的跑者，也适合随行支援估算需要携带的补给与衣物重量。它不适合三种情况：第一，你想比较不同品牌产品的性价比或选购推荐，工具不做品牌判断；第二，装备重量还没称量，凭印象填克重，占比和取舍建议都会失真；第三，赛事当届强制清单尚未公布，你把旧规程里的强制项当成当前要求。工具按干燥打包状态估算，吸水后的衣物、随身穿着层和寄存包都不在计数内。

## 输入与单位

体重以公斤为单位；背包自重、能量食物以克为单位；饮水以升为单位；装备清单一行一项，格式为 `名称,克重,是否强制`，强制位填 1 表示强制、0 表示自选，客户端会把它们分别归入强制与自选两组。

| 输入 | 单位 | 必填 | 范围与说明 |
| --- | --- | --- | --- |
| `bodyWeightKg` | kg | 是 | 体重，30–150 公斤 |
| `packWeightGrams` | g | 是 | 空背包自重，0–5000 克 |
| `waterLiters` | L | 是 | 携带饮水，0–5 升，按 1000 克/升换算 |
| `fuelGrams` | g | 是 | 能量食物重量，0–2000 克 |
| `mandatoryItems` | 行 | 是 | 规则强制携带的装备，每行 `名称,克重` |
| `optionalItems` | 行 | 是 | 自己选择带上的装备，每行 `名称,克重` |

填写时注意：克重应称打包后的实际重量，而不是产品标称重量；水壶要算入水的重量，空壶和满壶差别很大；能量胶、盐丸这类小件按整包携带量计入。强制位只反映你所参加赛事的规则要求，不代表这件东西你舍不得丢。名称控制在 40 字以内，便于结果表阅读。

## 公式、假设与舍入

工具先校验体重、背包、饮水和食物范围，再逐项校验名称、克重；装备总数至少一项、至多四十项。

- 强制装备重量 = 强制清单各项克重之和。
- 自选装备重量 = 自选清单各项克重之和。
- 基础重量 = 强制装备 + 背包自重。
- 背负重量 = 基础重量 + 自选装备 + 饮水 × 1000 + 能量食物。
- 总负重 = 背负重量。
- 占体重比例 = 总负重 ÷（体重 × 1000）× 100，保留一位小数。
- 最重单件 = 全部装备中克重最大的一项；重量相同时强制项优先。
- 取舍建议：负重占比超过体重 15% 时，提示优先复核自选装备；饮水超过 2 升时，提示确认赛道补给点间距与补水机会。

主要假设包括：重量为干燥打包状态；吸水衣物、身上穿着的层和寄存包未计入；强制标记依据参赛者自己掌握的赛事规则，工具不在比赛当天重新核对当届规程；15% 负重提示和 2 升饮水提示是规划启发式阈值，不是官方安全红线，地形、配速和天气都会改变同样负重的体感。舍入上，克重合计为整数，饮水按整升换算，占比保留一位小数。

## 怎么读结果

结果区先给出强制重量、自选重量、基础重量、背负重量、总负重、占体重比例和最重单件，最后是取舍建议列表。

| 输出 | 含义 | 怎么用 |
| --- | --- | --- |
| 强制装备 | 规则要求必须携带的重量 | 这部分不能通过裁剪解决，只能靠轻量化合规装备 |
| 自选装备 | 规则未要求、自己带上的重量 | 裁剪决策主要从这里开始 |
| 基础重量 | 强制装备加背包自重 | 判断背包本身在总重里占多大份额 |
| 背负重量 | 基础加自选、饮水与食物的全部重量 | 与以往比赛打包重量对照，判断是否偏重 |
| 总负重 | 背负总重，用于占比计算 | 对照身体感受和以往参赛记录 |
| 占体重比例 | 总负重占体重的百分比 | 超过 15% 时优先复核自选项 |
| 最重单件 | 克重最大的一项装备 | 先看这件是否有更轻的合规替代 |
| 取舍建议 | 负重偏高或饮水过大的提示 | 赛前重新称量并核对强制清单与补给安排 |

读结果时要注意：强制装备重量高，不能靠少带解决，只能通过选择更轻的合规装备降低；自选装备里最重的不一定最该丢，关键看它在比赛中的使用场景。占比低也不代表打包合理，若强制清单本身偏重，工具只能如实呈现。取舍建议不含品牌推销，也不推荐具体替换产品。

## 算例一：典型

体重 62 公斤，背包自重 450 克，饮水 1.5 升，能量食物 360 克。强制：防水冲锋衣 280 克、头灯 95 克、保温毯 120 克、导航设备 180 克；自选：能量胶四个 240 克、遮阳帽 45 克、备用薄外套 320 克。

| 项目 | 算式 | 结果 |
| --- | --- | --- |
| 强制装备 | 280 + 95 + 120 + 180 | 675 克 |
| 自选装备 | 240 + 45 + 320 | 605 克 |
| 基础重量 | 675 + 450 | 1125 克 |
| 背负重量 | 1125 + 605 + 1500 + 360 | 3590 克 |
| 占体重比例 | 3590 ÷ 62000 × 100 | 5.8% |
| 最重单件 | 备用薄外套 320 克 | 列入优先复核 |

背负总重 3.59 公斤，占体重约 5.8%，处于常规越野打包区间，未触发 15% 负重提示；饮水 1.5 升也未触发饮水提示。备用薄外套是最重的单件装备：如果当日天气预报稳定、冲锋衣已足够防护，它属于首先复核的对象；能量胶数量则要对照比赛时长和补给站距离决定，不能只看重量。头灯、导航这类强制项即使克重可观，也不会被建议裁掉。

## 算例二：边界

体重 70 公斤，背包自重 200 克，饮水 0 升，能量食物 0 克，只登记一项强制保温毯 200 克，自选为空。

| 项目 | 算式 | 结果 |
| --- | --- | --- |
| 强制装备 | 200 | 200 克 |
| 自选装备 | 0 | 0 克 |
| 基础重量 | 200 + 200 | 400 克 |
| 背负重量 | 400 + 0 + 0 + 0 | 400 克 |
| 占体重比例 | 400 ÷ 70000 × 100 | 0.6% |
| 最重单件 | 强制保温毯 200 克 | 无裁剪候选 |

只有一项强制装备时，基础与背负都等于强制重量加背包，自选为 0；没有可裁剪对象，建议列表为空。这个边界说明工具不会为了给出建议而虚构自选项，也不会把强制装备列入候选。占比 0.6% 只是数学结果，不代表这套打包完整——真实比赛还需要饮水、补给和其他装备，应逐项补全后再判断。

## 算例三：非法或缺失输入

第一种非法情况：体重填 20 公斤，超出 30–150 范围，工具按范围错误拒绝，错误字段为 `bodyWeightKg`。第二种：背包自重填 6000 克，超出 0–5000；饮水填 6 升，超出 0–5；能量食物填 2500 克，超出 0–2000；单项克重填 −50 克或 6000 克，超出 0–5000 范围，工具按范围错误拒绝。第三种：某一行缺少逗号、名称为空或克重不是数字，客户端按格式错误指出是第几行；这类错误不进入计算。

第四种：浏览器体重、背包或克重留空时得到非有限数值，工具按非有限错误处理，不把空字符串当成 0 克参与合计。强制标记写成其他文本而不是 1/0 时，客户端先提示格式，再决定归入哪一组。

## 与路线和知识的关系

强制装备的设置来自赛事规程。UTMB 系列规程发布全员适用的基础强制清单，并可根据天气预报单独激活附加强制装备，出发时基础项与激活项都必须携带；强制装备放在背包或腰包内，随时可出示，裁判途中可抽查，拒绝配合可被取消资格；缺少饮水储备、带帽防水外套、头灯、保温毯、手机等安全强制装备直接取消资格，其他强制装备缺失处时间罚；规程同时提醒不要一味选最轻服装，而要选择能防风、防雨、抗雪与低温的保护层。Western States 100 参与者指南要求，接近半程赛道在夜间通过时每人携带两支 LED 手电；赛事为无杯赛，自备可重复水杯；赛道温度可从接近冰点到 110 华氏度以上，需分层着装并通过团队或补给袋取用保暖层；陪跑不得为参赛者携带水、食物、手电、鞋服。这些口径可以对照 [UTMB 路线档案](/routes/utmb/) 阅读。

补给重量的安排有营养立场依据：国际运动营养学会超长距离马拉松立场声明建议，赛中每小时摄入 150–400 千卡、碳水 30–50 克、蛋白质 5–10 克，饮水 450–750 毫升；个体肠胃耐受差异很大，高摄入或高渗溶液是赛中胃肠不适的主要诱因之一。饮水系统的选择见 [补水系统](/knowledge/hydration-systems/)，补给与热量安排见 [赛事补给对比](/knowledge/race-fuel-comparison/)，越野衣物与装备原则见 [越野装备](/knowledge/trail-gear/)，随身检查项见 [赛事清单](/tools/race-checklist/)。

## 常见失败模式与早期信号

第一种失败模式是凭印象填克重。产品标称重量不含水、不含包装，满水壶和备用衣物的重量常被低估。早期信号：两次打包估算相差几百克，却说不出差在哪一项。

第二种是先砍安全装备。减重压力下最容易拿掉保温层、备用光源或应急联络设备，而这些恰是规程强制项。早期信号：取舍建议里出现了标记强制的项目，说明打包时强制位标错了。

第三种是只看总重，不看强制与自选结构。总重低可能是因为强制清单简单，而不是打包克制；总重高也可能来自不可削减的安全装备。早期信号：同样 3.5 公斤，别人轻装你却觉得背得很沉，应逐项核对结构。

第四种是忽略吸水与沿途补给。衣物出汗后增重、水壶沿途反复补水，背包重量随比赛进程变化；按出发时干燥状态算的总重不能代表全程负重。早期信号：你按空壶重量登记，却计划全程自给水。

## 适用边界

本工具适用于赛前整理打包、核对强制清单和比较装备方案的场景，覆盖公路马拉松与越野跑装备。它不做品牌对比、选购推荐或产品测评，不计算服装尺码、合身度和防护等级，也不评估装备在特定天气下是否足够。工具不构成医疗或安全建议；山区天气突变、体温过低或肠胃不适时，应按赛事规程和医疗流程处理，装备取舍不能替代安全判断。当届赛事强制清单、天气要求和补给站安排公布后，以官方规程为准。
