## 这个工具用于什么

跑步疼痛最容易被两种方式耽误：一种是带痛硬跑，另一种是因为害怕而长期完全停跑。这个自查用一个短清单把常见信号集中起来，帮你判断“继续观察”还是“应该找人评估”。它面向已经有跑步习惯、想在出现轻微疼痛时判断下一步处理方向的人，也可以作为记录症状、就诊时向专业人士描述情况的提纲。

它不给出诊断，也排除不了损伤。系统综述汇总 36 项研究、23,047 名跑者，26.2% 报告过跑步相关损伤，但训练参数与损伤之间的证据存在冲突；这意味着清单能提醒你关注信号，却不能证明某个部位“没事”或“有事”。NHS 的建议更直接：不要带痛跑步；疼痛严重、持续或伴随肿胀时，应寻求医疗或物理治疗建议。

## 输入与输出

输入有七项：跑步时是否疼痛、休息或走路时是否疼痛、是否肿胀、是否有夜间或晨起疼痛、近一周跑量变化百分比、最近每晚睡眠小时数、同一部位是否曾经受伤。输出包括自查总分、区间（低、中、高）、是否存在红旗信号，以及一段建议文字。分数把几项经验权重相加，区间只是把分数映射成三档提示；红旗信号单独判定，优先级高于总分。工具不输出影像结论、损伤名称、恢复时间或个体化运动处方。

## 公式与规则

自查采用加权计分，每一项按经验权重相加：

| 项目 | 条件 | 分值 |
| --- | --- | --- |
| 跑步时疼痛 | 是 | 1 |
| 休息或走路时疼痛 | 是 | 2 |
| 肿胀 | 是 | 2 |
| 夜间或晨起疼痛 | 是 | 1 |
| 近一周跑量变化 | 大于 +10% | 1 |
| 最近睡眠 | 少于 7 小时/晚 | 1 |
| 同一部位曾经受伤 | 是 | 1 |

总分为 0 至 9 分：0 至 2 分为低区间，3 至 4 分为中区间，5 分及以上为高区间。休息或走路时疼痛、肿胀任一项为真，就记为红旗信号，结果文字会直接建议“应寻求评估”，而不只是看总分。权重、10% 跑量阈值和 7 小时睡眠线都是经验性启发式，不是临床预测规则；跑步相关损伤的证据本身存在冲突，这些阈值不能当作因果结论。

跑量变化按百分比填写：+12 表示比上周增加 12%，−10 表示减少 10%。减少跑量不会加分，工具不会因为“减量”而给出更低的分数；它只判断是否超过 +10% 这一经验线。

## 算例一：低区间

算例一：跑步时疼痛、同一部位曾经受伤，其余为否；跑量 +6%，睡眠 7.5 小时。分数为 1 + 1 = 2，落在低区间，没有红旗信号。

| 项目 | 取值 | 分值 |
| --- | --- | --- |
| 跑步时疼痛 | 是 | 1 |
| 静息或走路痛、肿胀、夜间痛 | 否 | 0 |
| 跑量变化 | +6% | 0 |
| 睡眠 | 7.5 小时 | 0 |
| 同一部位既往伤 | 是 | 1 |
| 合计 |  | 2（低） |

低区间表示当前没有报告红旗信号，可以继续观察并记录症状，但不等于症状可以忽略；疼痛若在后续几天加重或出现新信号，应重新评估。

## 算例二：中区间

算例二：跑步时疼痛、夜间或晨起疼痛、跑量 +12%、睡眠 6 小时，其余为否。分数为 1 + 1 + 1 + 1 = 4，落在中区间，仍没有红旗信号。

| 项目 | 取值 | 分值 |
| --- | --- | --- |
| 跑步时疼痛 | 是 | 1 |
| 夜间或晨起疼痛 | 是 | 1 |
| 跑量变化 | +12% | 1 |
| 睡眠 | 6 小时 | 1 |
| 静息或走路痛、肿胀、既往伤 | 否 | 0 |
| 合计 |  | 4（中） |

中区间提示先降低负荷、减少跑量或强度并观察；若疼痛持续、加重或伴随肿胀，应寻求医疗或物理治疗评估。

## 算例三：高区间与红旗信号

算例三：跑步时疼痛、休息或走路时疼痛、肿胀、跑量 +15%、睡眠 5.5 小时；夜间痛为否，既往伤为否。逐项计分：跑步痛 1 + 静息或走路痛 2 + 肿胀 2 + 跑量超过 +10% 1 + 睡眠少于 7 小时 1 = 7 分，落在高区间；静息或走路痛与肿胀同时为真，红旗信号为真。

| 项目 | 取值 | 分值 |
| --- | --- | --- |
| 跑步时疼痛 | 是 | 1 |
| 静息或走路痛 | 是 | 2 |
| 肿胀 | 是 | 2 |
| 夜间或晨起疼痛 | 否 | 0 |
| 跑量变化 | +15% | 1 |
| 睡眠 | 5.5 小时 | 1 |
| 同一部位既往伤 | 否 | 0 |
| 合计 |  | 7（高），红旗为真 |

这个算例说明红旗信号与总分是两条判断线：即使分数不高，只要出现静息痛、走路痛或肿胀，就应停止跑步并寻求评估。清单不给个体化运动处方，康复与复跑安排要由专业评估决定。

## 红旗信号与就医边界

以下情况不等待清单分数，应直接停止跑步并寻求医疗或物理治疗评估：休息或走路时疼痛、可见或可触及的肿胀、夜间或晨起持续疼痛、步态改变、无法负重、明显畸形、红肿热痛迅速加重、发热，以及急性外伤后出现的剧痛。若出现关节畸形、无法活动、麻木发凉、严重肿胀或意识相关症状，按紧急情况处理并呼叫急救。红旗信号的意义是“需要进一步检查”，而不是“已经确诊某种伤病”；具体诊断、影像和恢复计划由临床人员完成。

## 舍入与精度

分数是整数相加，没有取整误差，容差为 0；跑量变化和睡眠只用于阈值比较，不参与加权计算。边界按“含下界”处理：0 至 2 分为低，3 至 4 分为中，5 分及以上为高；跑量正好 +10% 不加分，超过 +10% 才加 1 分；睡眠正好 7 小时不加分，少于 7 小时才加 1 分。输入本身依赖你的主观回忆，误差来源主要是“疼痛是否算疼痛”的判断，而不是算术。

## 结果解读

低区间表示当前没有报告红旗信号，可以继续观察，但不等于可以忽略症状；中区间提示减少负荷并观察，如果疼痛严重、持续或出现肿胀，应寻求医疗或物理治疗建议；高区间表示多个因素同时存在，应降低负荷并在症状持续时寻求评估。静息痛、走路痛或肿胀比总分更重要，因为 NHS 明确建议不要在疼痛中跑步，并在疼痛严重、持续或伴随肿胀时就医。

持续疲劳、表现下降或平台期还应促使考虑过度训练综合征并排除潜在疾病；这类评估是临床性的，没有单一诊断指标，处理方向包括休息和纠正训练与恢复失衡的因素。

## 常见误区

第一个误区是把低分数当成“可以继续跑”的许可：分数只是经验清单，红旗信号和身体感受优先于分数。第二个误区是凭分数判断具体伤病名称：清单不做诊断，也不能排除损伤。第三个误区是只看跑量变化：睡眠、既往伤和疼痛模式同样进入判断。第四个误区是用清单替代复跑计划：什么时候恢复跑步、以什么强度恢复，需要结合专业评估，而不是由分数决定。

## 适用边界

本工具面向一般跑步人群的自我观察，不适用于急性外伤、无法负重、明显畸形、发热、红肿热痛迅速加重或术后康复等情况，这些应直接就医。它不诊断具体损伤，不排除损伤，也不判断何时可以恢复跑步；恢复训练需要结合专业评估。清单不能替代影像、体格检查或医疗建议，也不能用来证明“可以继续跑”。儿童、孕期跑者和有既往严重伤病的跑者应先咨询专业人员。本工具不构成医疗诊断或运动处方。

## 使用步骤

1. 按最近一周的实际情况回答 7 个问题，跑量变化用百分比表示，睡眠取最近几晚的平均值。
2. 读取分数、区间和建议文字；先看是否有静息痛、走路痛或肿胀，再看总分。
3. 低区间继续观察并记录症状；中或高区间降低负荷；出现红旗信号时停止跑步并寻求医疗或物理治疗评估。
