## 这个工具算什么，什么时候不能用

想报波士顿马拉松这类按成绩门槛选拔的赛事，先要弄清两件事：你的完赛成绩对应哪个年龄性别标准，以及这个成绩算不算数。这个工具把赛事类型、性别口径、比赛当日年龄、近期完赛成绩和赛道认证状态放在一起，查出官方资格标准，计算与标准的余量分钟数，给出是否达标的判定，列出缺失的条件代码，并附上规则说明：达到标准只获得申请资格，名额受限时更快的申请者仍可能被 cutoff 排除；资格成绩必须来自官方公开、认证丈量的赛道，GPS、手表或 Strava 记录不被接受。

它适合已经有一场正式完赛、想核对是否达到目标赛事门槛的马拉松跑者，也适合赛前训练安排时反推需要跑到什么成绩。它不适合三种情况：第一，你还没有正式比赛成绩，想用训练跑或跑步记录充当资格；第二，赛事当届规则调整了标准表、资格窗口或年龄口径，而你手上的还是旧版本；第三，需要审核成绩日期是否落在报名资格窗口内——本工具不校验日期，这一项必须对照当届规则确认。工具按 2026-11-25 可见的官方标准实现，未来赛季可能修订。

## 输入与单位

成绩以分钟为单位，年龄按比赛当日计算；赛事与性别为下拉口径；赛道认证为是/否标记。

| 输入 | 单位 | 必填 | 范围与说明 |
| --- | --- | --- | --- |
| `event` | 枚举 | 是 | `boston` 波士顿马拉松，`comrades` 同志马拉松 |
| `sex` | 枚举 | 是 | `M` 男子，`F` 女子 |
| `ageOnRaceDay` | 岁 | 是 | 比赛当日年龄，18–90 |
| `qualifyingTimeMinutes` | 分钟 | 是 | 资格完赛成绩，1–600 分钟 |
| `qualifierCourseCertified` | 布尔 | 是 | 资格赛道是否经认证丈量 |

填写时注意：年龄以比赛当日为准，不是报名当天；成绩填写官方净计时（chip time），不是枪声时间；赛道认证指赛道持有有效的国际丈量证书，起终点间距与海拔落差都在认证核查范围内。如果资格赛是越野跑、跑步机或未认证公路赛，即使成绩更快，也不能作为这两类赛事的资格依据。

## 公式、假设与舍入

工具先校验赛事、性别、年龄、成绩和认证标记的取值范围，再按赛事查标准。

- 波士顿：按比赛当日年龄落入官方年龄组；`M` 取男子标准，`F` 取女子标准。
- 同志马拉松：开放组别，统一标准 300 分钟（官方上限 4:59:59，本闸门按 5:00:00 取整）。
- 余量 = 标准分钟数 − 资格成绩分钟数，取整到整分钟；正数表示快于标准，负数表示慢于标准。
- 达标条件：赛道认证标记为真，且资格成绩 ≤ 标准；任一不满足，达标为假。
- 缺失条件：赛道未认证时记为 `certified-course`；赛道已认证但成绩超标时记为 `time`；两者都满足时为 `null`。
- 规则说明：波士顿达到标准只获得申请资格，名额有上限时按成绩 cutoff；同志马拉松只接受合规赛事的官方公开成绩，GPS、Strava 与手表分段不被接受。

主要假设包括：所填成绩是官方公布、认证赛道上的净计时；工具套用 2026-11-25 有效的标准，未来届次可能修订；工具不核查资格日期是否落在接受窗口内；年龄按比赛当日、按官方年龄组边界归类。舍入上，余量取整到整分钟，标准与成绩均按整分钟处理。

## 怎么读结果

结果区给出标准分钟、余量、是否达标、缺失条件代码和规则说明。

| 输出 | 含义 | 怎么用 |
| --- | --- | --- |
| 资格标准 | 对应年龄性别组的官方门槛（分钟） | 对照自己的最佳正式成绩 |
| 余量 | 标准减成绩，正数为余量，负数为欠量 | 余量越小，越需要在训练中留提升空间 |
| 是否达标 | 认证且成绩达标的综合判定 | 假分时先查缺失条件，再看成绩差距 |
| 缺失条件 | `certified-course`、`time` 或 `null` | 赛道未认证时，成绩本身再快也不能算资格 |
| 规则说明 | 申请名额限制与成绩来源口径 | 报名前阅读当届规程原文 |

读结果时要注意：达标不等于中签。波士顿的接受名额有上限，达到标准的申请者仍可能被成绩截止线排除；余量 3 分钟并不稳妥，因为下一届标准可能调整，你的成绩也可能波动。赛道未认证时，工具判定为不达标并把缺失条件记为 `certified-course`，即使成绩数字快于标准；成绩已认证但慢于标准时，缺失条件记为 `time`。同志马拉松的开放标准不区分年龄性别，但资格日最低年龄为 20 岁，且成绩必须来自至少 42.2 公里的合规赛事；本工具按规格接受 18–90 岁输入，年龄下限口径以当届 FAQ 为准。

## 算例一：典型

波士顿，`M`，比赛当日 32 岁，资格成绩 172 分钟（2:52），赛道已认证。

| 项目 | 算式 | 结果 |
| --- | --- | --- |
| 资格标准 | 18–34 男子 | 175 分钟（2:55:00） |
| 余量 | 175 − 172 | 3 分钟 |
| 缺失条件 | 赛道已认证且成绩达标 | `null` |
| 判定 | 172 ≤ 175 且已认证 | 达标 |

成绩快于男子标准 3 分钟，赛道认证齐全，判定达标。需要注意，这 3 分钟只是相对标准的余量：波士顿名额受限时，cutoff 可能快于基础标准；若成绩来自下坡净落差赛道或未丈量证书有效期内的赛事，还需按 BAA 规则复核成绩有效性。

## 算例二：边界

同志马拉松，`F`，35 岁，资格成绩正好 300 分钟，赛道已认证。

| 项目 | 算式 | 结果 |
| --- | --- | --- |
| 资格标准 | 开放组别 | 300 分钟 |
| 余量 | 300 − 300 | 0 分钟 |
| 缺失条件 | 赛道已认证且成绩达标 | `null` |
| 判定 | 300 ≤ 300 且已认证 | 达标 |

成绩正好压在标准线上，余量为 0，判定达标。这个边界说明“等于标准”算达标，不需要再快几秒；但官方上限为 4:59:59，本工具按 300 分钟闸门处理，压线成绩应在报名前对照官方计时确认。资格赛必须是至少 42.2 公里、符合技术与核验标准的赛事，且成绩为官方公开记录。

## 算例三：非法或缺失输入

第一种非法情况：比赛当日年龄填 15，低于 18 岁下限，工具在查标准之前按范围错误拒绝，错误字段为 `ageOnRaceDay`。第二种：成绩填 0 或 700 分钟，超出 1–600 范围；赛事或性别填入表外取值，工具按枚举错误拒绝。第三种：赛道认证标记留空或传入非布尔值，工具按范围错误处理。

第四种：成绩来自未认证赛道，工具仍算出标准与余量，但达标判定为假，缺失条件为 `certified-course`；这种情况不是成绩差距问题，而是成绩来源不被接受。第五种：浏览器成绩或年龄留空时得到非有限数值，工具按非有限错误处理，不把空字符串当成 0 参与比较。

## 与路线和知识的关系

资格成绩的有效性建立在赛道丈量与认证之上。World Athletics 认证公路赛事持有经认可丈量员签发的国际赛道丈量证书，证书五年有效；认证核查起终点间距、赛道允许海拔落差和丈量程序本身；证书失效或缺失的赛道，其成绩不能作为认证成绩使用。这一口径与 [纪录与赛道有效性](/knowledge/records-and-course-validity/) 中的赛道认证原则一致。马拉松距离与成绩口径见 [马拉松距离](/knowledge/marathon-distance/)，比赛日节奏安排见 [比赛日配速](/knowledge/race-day-pacing/)。

两类目标赛事的官方档案可对照阅读：[波士顿马拉松](/routes/boston/) 的标准表按年龄性别分列，达到标准仅开放申请；[同志马拉松](/routes/comrades-marathon/) 要求合规赛事官方公开成绩，资格窗口按届次公布。工具内的标准表来自 BAA 官方资格页面与 Comrades 官方 FAQ，未收录其他按成绩选拔赛事的门槛。

## 常见失败模式与早期信号

第一种失败模式是把训练跑或手表记录当成资格成绩。资格只认官方公布的完赛记录，GPS 轨迹、Strava 分段和跑步机成绩不能替代。早期信号：你填入的最佳成绩没有对应赛事名称、名次或官方链接。

第二种是用错年龄组或性别口径。临近年龄边界报名、跨组别参赛时，标准表归类会变。早期信号：你参照的是上一年龄段的成绩，或性别口径填反了表。

第三种是忽略认证状态。成绩快但赛道未丈量、证书过期或落差超标，成绩在资格审核中不被接受。早期信号：资格赛是本地半程改道、越野短道或自家附近的环线，没有可查的丈量证书编号。

第四种是把达标当成中签。名额 cutoff 可能快于基础标准，达标者仍可能落选；余量不足的跑者应把训练目标定在标准之内，而不是刚好压线。早期信号：你以最近一次最佳成绩对照，却没有留成绩波动和标准上调的余地。

## 适用边界

本工具适用于对照波士顿马拉松与同志马拉松官方资格标准的赛前核对，不覆盖其他按成绩选拔赛事的门槛，也不审核报名资格窗口、成绩日期、赛事名次或候补规则。工具不构成参赛承诺；成绩有效性、认证状态和资格日期最终由赛事组委会按当届规程认定。当届标准表、接受窗口或年龄口径调整时，以赛事官网最新公告为准。
