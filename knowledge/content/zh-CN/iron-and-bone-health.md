## 为什么把铁和骨放在一页

铁和骨看起来是两个系统，但在跑者身上经常一起出问题。铁参与血红蛋白和肌红蛋白的氧运输，缺铁会降低耐力表现；骨应力损伤（bone stress injury，BSI）则是跑步负荷超过骨组织修复能力的结果。2025 年的一篇综述把**铁缺乏**列为骨应力损伤的风险因素之一，和女性、竞争性参赛、问题性低能量可用性（LEA）、维生素 D 缺乏、月经周期不规则、训练处方错误并列。

这不是说「缺铁一定导致骨折」，也不是说「补铁就能防骨折」。它说明：反复疲劳、表现下降、反复骨痛和月经改变，可能共享同一个底层问题——能量和营养不足以支撑当前训练量。

## 铁蛋白怎么读

铁蛋白（serum ferritin）是常用的铁储存指标。Alaunyte 2015 的综述给出这些区间与事实：

| 项目 | 数值或结论 |
|---|---|
| 成年女性生理范围 | 15–200 μg/L |
| 潜伏缺铁的下限 | 不同研究用 12–35 μg/L，差异很大 |
| 12 μg/L 的含义 | 通常表示骨髓铁储备缺失、储存完全耗竭 |
| 吸收与铁蛋白的关系 | 铁蛋白升到约 60 μg/L 之前，吸收随铁蛋白升高而下降 |
| 铁蛋白 10 μg/L 时 | 血红素与非血红素铁的吸收都约为 40% |
| 铁蛋白升高后 | 吸收下降，非血红素铁下降更明显 |

这意味着「铁蛋白低一点但还没贫血」并不等于没问题。缺铁分三个阶段：储存耗竭（铁蛋白下降）、红细胞生成受影响（血清铁下降、转铁蛋白饱和度下降）、最后才是贫血（血红蛋白下降）。前两个阶段合称「潜伏缺铁」或「缺铁不贫血」，可能已经影响表现，但常规血常规不一定提示。

**不要只看血红蛋白。** 血红蛋白正常不能排除缺铁；铁蛋白、血常规和医生的判断需要一起看。不同实验室、不同炎症状态下铁蛋白的解释也会变化，本页不提供自我诊断阈值。

## 铁摄入与吸收：为什么「吃了很多铁」仍可能缺铁

| 事实 | 含义 |
|---|---|
| 血红素铁吸收率可达 40%，非血红素铁只有 2%–20% | 动物来源的铁吸收效率更高 |
| 血红素铁只占膳食铁约 10% | 大部分膳食铁是非血红素铁 |
| 西方饮食约 50% 的膳食铁来自谷物 | 主食和强化食品是重要来源，但吸收受植酸等影响 |
| 英国成年女性参考摄入量 14.8 mg/天，美国推荐膳食允许量 18 mg/天 | 国家推荐值针对一般成年女性，不是运动员个体处方 |
| 有作者建议耐力女性跑者增加约 70% | 折算约在 14.8 mg 基础上再加 10 mg；这是建议，不是官方统一标准 |
| 素食跑者铁蛋白 7.4 μg/L，肉食者 19.8 μg/L | 总铁摄入相近，但可吸收铁为 0.66 vs 0.91 mg/天 |

促进非血红素铁吸收的因素包括维生素 C、某些有机酸、肉、鱼和贝类；抑制因素包括植酸、酚类化合物和钙。把富含铁的食物与维生素 C 一起吃，是比「多吃菠菜」更实际的思路。茶、咖啡和钙补充剂与正餐的时间关系，也值得记录后再调整。

**本站不给补铁剂量。** 是否补、补多少、补多久，需要根据铁蛋白、血红蛋白、炎症状态、月经量和胃肠道耐受由医生决定。自行长期补铁有铁过载风险，也可能掩盖消化道失血等问题。

## 骨应力损伤的规模

Crunkhorn 2025 的综述汇总了这些数字：

| 项目 | 数据 |
|---|---|
| 在越野、田径、铁人三项、铁人两项和休闲跑者中占肌肉骨骼损伤的比例 | 15%–20% |
| 下肢占比 | 80%–95% |
| 胫骨 | 49% |
| 跗骨 | 25% |
| 女性跑者相对男性的发生率 | 1.8–2.3 倍 |
| 女性铁人三项相对男性 | 2.9 倍 |
| 训练中发生 vs 比赛中发生 | 66% vs 7%（澳大利亚 48 个项目、3 年审计） |
| 3 年内发生 2 次及以上 | 15% |
| 板球腰椎复发率 | 39% |
| 高中有记录的发病率 | 1.5/100,000 运动员暴露 |
| NCAA 发病率 | 5.7/100,000 运动员暴露 |

这些数字说明骨应力损伤不是罕见事件，尤其在跑量高、负荷变化快、能量可用性低的人群。它们也说明**复发**是重要特征：一次骨应力损伤处理不当，下一次的风险更高。

## 能量可用性：铁与骨的交汇点

2023 年 IOC REDs 共识把能量可用性（energy availability，EA）定义为：

```
EA =（能量摄入 − 运动能量消耗）/ 去脂体重 / 天
```

共识给出的低能量可用性或 REDs 指标患病率区间是：女性 23%–79.5%，男性 15%–70%。它区分「可适应的低能量可用性」与「问题性低能量可用性」；后者与肌肉骨骼健康下降、受伤风险上升和表现下降相关。

对跑者来说，重要的不是记住公式，而是识别模式：

- 长期能量摄入不足以覆盖训练消耗；
- 体重非计划下降，或长期低体重；
- 月经周期改变、闭经；
- 反复骨应力损伤或骨痛；
- 持续疲劳、怕冷、睡眠变差、情绪低落；
- 表现下降，但训练量还在增加。

这些信号需要临床评估。**不要用「再多吃一点」或「再减一点体重」自行处理**；问题性低能量可用性涉及内分泌、骨代谢、心理和营养多个系统。

## 哪些情况更容易出现骨应力损伤

综述列出的风险因素包括：女性、竞争性参赛、问题性低能量可用性、维生素 D 或铁缺乏、月经周期不规则、训练处方错误。还有一些具体人群数据：

- 女性青少年运动员每周训练 12–16 小时或更多，风险升高；
- 男性青少年每周跑超过 30 英里（约 48 公里），风险升高；
- 骨应力损伤在训练中发生的比例远高于比赛；
- 下肢承重骨（胫骨、跗骨）最常见。

这些是群体层面的风险因素，不能用来给个人下诊断。它们的作用是提示：如果你同时具备多项，出现局部骨痛时应更早评估，而不是继续加量。

## 识别与就医边界

| 表现 | 处理 |
|---|---|
| 局部、固定的一小点骨痛，按压痛，跑跳时加重 | 停止加重负荷，尽快运动医学评估；可能需要影像 |
| 休息时痛、夜间痛、走路跛行、无法负重 | 尽快就医，不要继续跑 |
| 疼痛伴明显肿胀、局部发热、近期外伤 | 尽快就医，排除骨折与其他损伤 |
| 反复同一部位骨痛，或多次应力性损伤 | 评估能量可用性、铁状态、维生素 D、月经周期与训练负荷 |
| 月经周期改变、闭经、非计划体重下降 | 尽早就医，不要把它们当成训练成果 |
| 胸痛、晕厥、严重心悸、无法缓解的呼吸困难 | 按急症处理 |

本页不提供影像判读、不判断骨折分级、不给止痛药或补剂建议。骨应力损伤的严重程度、部位和复跑时间需要临床与影像评估；有些部位（如某些跗骨、股骨颈）风险更高，不能按「休息两周」处理。

## 可以做的事（不是处方）

- 保证总能量摄入覆盖训练消耗，而不是长期赤字；
- 每餐有碳水、蛋白质和蔬菜，避免把「低体重」当成表现目标；
- 铁来源多样化，植物性铁与维生素 C 同餐，注意茶/咖啡/钙与正餐的间隔；
- 不自行长期补铁、不自行大剂量补维生素 D；
- 训练负荷一次只改一个变量，骨痛出现时先减量而不是加量；
- 女性记录月经周期，青少年记录身高体重与训练时长；
- 出现红旗时就医，不靠搜索引擎自我诊断。

## 常见误区

- **「血红蛋白正常就不缺铁」**：缺铁可以在贫血之前发生，铁蛋白和血常规需要一起看。
- **「多吃菠菜就能补铁」**：植物性铁吸收率低，且受植酸影响；总铁量和吸收条件都重要。
- **「铁蛋白低就自己买铁剂」**：补铁需要医生评估，长期自行补铁有铁过载风险。
- **「骨痛是跑量大的正常反应」**：固定点骨痛、夜间痛、跛行是需要评估的信号。
- **「休息两周所有骨痛都会好」**：不同部位、不同严重程度差异很大，部分部位需要更严格的处理。
- **「闭经说明训练到位」**：闭经是能量可用性不足的警示信号之一，不是勋章。
- **「补维生素 D 就能防所有骨损伤」**：维生素 D 是因素之一，不能替代能量、铁、训练负荷和月经状态的综合评估。

## 检查清单

- [ ] 我是否知道自己的铁蛋白和血红蛋白最近一次结果？
- [ ] 我是否把「正常血红蛋白」当成「不缺铁」？
- [ ] 我的总能量摄入是否长期低于训练消耗？
- [ ] 我是否有月经周期改变、非计划体重下降或反复骨痛？
- [ ] 我是否在自行长期补铁或大剂量补维生素 D？
- [ ] 出现固定点骨痛、夜间痛或跛行时，我是否停止加量并就医？
- [ ] 我是否把「低体重」或「闭经」当成表现目标？

## 适用边界

本页是健康教育，不构成诊断、治疗或营养处方，不给补铁剂量、不给用药建议。铁蛋白阈值、骨应力损伤分级和复跑时间都需要临床评估；孕期、产后、青少年、素食者、有进食障碍史、消化道疾病、慢性病或使用影响骨代谢药物的人，应在医生或注册营养师指导下处理。急症信号按急症处理。
