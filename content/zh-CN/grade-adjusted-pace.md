## 这个工具用于什么

同一段路，上坡跑 6:00/公里和下坡跑 6:00/公里，身体付出的代价完全不同。这个工具把「坡度」和「实际配速」合成一个可比较的量：先算出该坡度下的跑步能耗，再换算成**同等代谢代价的平路配速**（grade-adjusted pace，常缩写为 GAP）。它适合用来比较多条路线的训练负荷、记录一段爬坡的真实强度，或者在复盘时把「今天跑得慢」和「今天坡多」分开看。

它不预测比赛成绩，也不告诉你「在平路上一定能跑多快」。等效配速回答的是「如果代谢代价相同，平路上的配速是多少」，而不是「你的能力是多少」。体能、疲劳、海拔、气温、风向、路面和技战术都不在公式里。

## 公式与区间规则

坡度用百分比表示：`i = 坡度（%）/ 100`，上坡为正、下坡为负。跑步能耗采用 Minetti 等（2002）在跑步机上拟合的五次多项式，单位为焦耳每千克每米（J/kg/m）：

```
Cr(i) = 155.4·i⁵ − 30.4·i⁴ − 43.3·i³ + 46.3·i² + 19.5·i + 3.6
```

平路（i = 0）的能耗是常数项 3.6 J/kg/m。定义能耗倍数：

```
能耗倍数 = Cr(i) / 3.6
平路等效配速 = 实际配速 / 能耗倍数
```

上坡时 Cr 大于 3.6，倍数大于 1，所以等效配速的数值更小（更快）；下坡在中等坡度时 Cr 小于 3.6，倍数小于 1，等效配速的数值更大（更慢）。公式的适用范围是 −45% 到 +45%，这与原研究的跑步机坡度范围一致。

以实际配速 5:00/公里（300 秒/公里）为例：

| 坡度 | 能耗（J/kg/m） | 相对平路 | 平路等效配速 |
|---|---|---|---|
| −30% | 2.462 | 0.684 | 7:19/公里（439 秒） |
| −20% | 1.800 | 0.500 | 10:00/公里（600 秒） |
| −10% | 2.152 | 0.598 | 8:22/公里（502 秒） |
| −5% | 2.746 | 0.763 | 6:33/公里（393 秒） |
| 0% | 3.600 | 1.000 | 5:00/公里（300 秒） |
| +5% | 4.685 | 1.301 | 3:51/公里（231 秒） |
| +10% | 5.968 | 1.658 | 3:01/公里（181 秒） |
| +20% | 9.007 | 2.502 | 2:00/公里（120 秒） |
| +30% | 12.579 | 3.494 | 1:26/公里（86 秒） |

这张表也暴露了模型的一个反直觉之处：下坡的能耗在约 −20% 附近最低，坡度再陡反而上升（−30% 的能耗已高于 −20%）。这是多项式本身的形状，不代表真实下坡跑「越陡越省力」；真实下坡还要制动、吸收冲击，并承受离心收缩带来的肌肉损伤。

## 验证算例

**算例一（上坡）**：实际配速 360 秒/公里（6:00/公里），坡度 +8%。

| 项目 | 计算 | 结果 |
|---|---|---|
| 坡度小数 | 8 / 100 | 0.08 |
| 能耗 | 155.4×0.08⁵ − 30.4×0.08⁴ − 43.3×0.08³ + 46.3×0.08² + 19.5×0.08 + 3.6 | 5.43342 J/kg/m |
| 倍数 | 5.43342 / 3.6 | 1.50928 |
| 等效配速 | 360 / 1.50928 | 238.53 → 239 秒/公里（3:59/公里） |

**算例二（下坡）**：实际配速 300 秒/公里（5:00/公里），坡度 −10%。

| 项目 | 计算 | 结果 |
|---|---|---|
| 坡度小数 | −10 / 100 | −0.10 |
| 能耗 | 155.4×(−0.10)⁵ − 30.4×(−0.10)⁴ − 43.3×(−0.10)³ + 46.3×(−0.10)² + 19.5×(−0.10) + 3.6 | 2.1524 J/kg/m |
| 倍数 | 2.1524 / 3.6 | 0.59789 |
| 等效配速 | 300 / 0.59789 | 501.77 → 502 秒/公里（8:22/公里） |

两个算例都可以手工复核。注意等效配速的方向：上坡的等效配速比实际配速快，下坡的等效配速比实际配速慢。

## 舍入与精度

能耗保留三位小数，倍数保留三位小数，等效配速取整到秒，因此配速的容差为 1 秒；倍数与能耗的容差为 1e-6。取整只发生在最后一步，等效配速由未舍入的倍数计算，避免先舍入再除造成累积误差。

输入本身有精度限制：手表给出的坡度是气压或 GPS 估算，短段落的瞬时坡度误差可能很大；比赛路线图的分段海拔也常有几米的误差。建议用一段至少几百米的平均坡度，而不是单点读数。模型假设整段坡度恒定，真实路线的坡度是连续变化的。

## 结果解读

- **上坡**：等效配速更快，说明同样的实际配速在上坡付出了更多代价。它可以用来判断「这段爬坡是否已经接近阈值强度」，而不是让你在平路上跑出那个速度。
- **中等下坡**：模型认为下坡更省能，所以等效配速更慢。真实下坡的离心负荷和制动成本没有进入公式，越陡的下坡越不能只看这个数字。
- **陡下坡（约 −25% 以下）**：模型里能耗不再下降甚至回升，但这并不意味着陡下坡更安全或更费力；它只说明多项式在此处已经不能代表真实的下坡成本。
- **比较路线**：把每段的「实际配速」和「等效配速」都记录下来，可以看出一条路线的真实强度分布，而不是只被总爬升数字影响。
- **不用于比赛预测**：等效配速不是等价成绩。比赛还受糖原、补水、热、海拔、下坡离心损伤和战术影响。

## 使用步骤

1. 选一段坡度相对均匀的路，记录这一段的距离、爬升或平均坡度，以及这一段的平均配速（秒/公里）。
2. 在工具里填入实际配速与平均坡度，读取能耗、倍数和平路等效配速。
3. 把等效配速写进训练日志，和同一条路线的历史数据比较，而不是和别人的平路配速比较。
4. 如果坡度超过 ±20%，把结果当作粗略参考，并结合体感、心率和下坡后的肌肉反应判断。

## 适用边界

本工具适用于公路、跑道和缓坡的稳态跑，不适用于需要绳索、冰雪或技术地形的路线，也不适用于走跑交替、间歇跑或坡度剧烈变化的路段。它不替代教练判断、比赛策略或医疗建议；有伤病、心血管疾病或在高温高海拔环境中训练的人，应先处理那些更重要的变量。坡度超出 −45% 到 45%、配速小于等于 0 或输入不是有限数时不计算。

模型来自十名精英山地跑者在跑步机上的测试，样本小、场景受控；它不能代表所有人群、所有路面和所有疲劳状态。下坡的离心损伤、制动、技术难度和心理成本都不在模型内。生物力学综述进一步指出，上坡的步频更高、腾空更短，下坡的腾空时间更长、后跟着地更多，且下坡以离心工作和能量耗散为主（knowledge-uphill-downhill-running）；这些机制不是一条多项式能完全表示的。

## 什么时候不该用这个数

模型来自十名精英山地跑者的跑步机测试，只在 −45% 到 +45% 的恒定坡度、稳态跑下成立。真实赛道的坡度连续变化，分段切得越短，GPS 高程噪声越容易把局部坡度放大成十几甚至几十个百分点，逐段 GAP 会剧烈抖动。下坡段没有计入制动、离心损伤和技术难度，所以「下坡等效配速更快」不等于下坡能真的跑那么快；海拔、热、风、路面和体重也不在模型里。

这个数不能用来预测完赛时间，也不能当作越野难度评级或训练强度处方。把它跨距离、跨地形外推，误差会叠加而不是抵消。

## 来源与适用范围

跑步能耗五次多项式、−0.45 到 +0.45 的坡度范围、平路常数 3.6 J/kg/m 与 R² = 0.99，来自 Minetti、Moia、Roi、Susta 与 Ferretti 发表于《Journal of Applied Physiology》的论文（2002）。「用能耗比值换算等效配速」是本站基于该多项式采用的换算方法，不是原论文给出的比赛成绩公式；原论文测量的是跑步机上稳态跑的代谢能耗，不涉及比赛表现预测。

上坡/下坡的生物力学差异（步频、腾空时间、后跟着地与离心工作）来自《Biomechanics and Physiology of Uphill and Downhill Running》综述（knowledge-uphill-downhill-running），用于说明模型的边界，不用于计算。
